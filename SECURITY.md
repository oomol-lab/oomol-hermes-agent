# Security Policy

Do not open a public issue containing credentials, connector responses, private
URLs, user data, generated session files, or container runtime state.

Before the first public release, OOMOL must publish a monitored private security
contact here. Until then, report suspected vulnerabilities through OOMOL's
existing private support channel.

Supported versions will be listed after the first release. The `main` branch is
development code and is not yet a supported security release.
